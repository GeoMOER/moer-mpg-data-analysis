# Instructor data and Unit 03 rendering

The active Unit 03 land-use examples now use the public, attributed Destatis 2024 files in `docs/assets/data/`. Their preparation is documented by `prepare-land-use-2024.R` and `destatis-land-use-2024-source.txt`; the prepared RDS has 16 state-level observations for one year. The teaching CSV and RDS use English headers and region names; the original German workbook and dictionary crosswalk preserve the source labels. Rebuild the English CSV with `python3 staging/examples/translate_land_use_2024.py` from the repository root before regenerating the RDS.

For a portable learner render, copy the Unit 03 land-use files into a `Data/` folder in a temporary project and render `unit03-04_csv_io.Rmd` or `unit03-06_exploration.Rmd` with that project as `knit_root_dir`. `unit03-03_visualization.Rmd` uses built-in R datasets. Instructor renders may set the option `mpg.unit03.fig.path` to an isolated output directory. Inspect new rendered Markdown and figures before publishing them; the Jekyll frontmatter, links and image paths are maintained separately.

Any older ILIAS data copies in this directory are ignored and are not the active Unit 03 examples. They must not be committed to the public repository.

## Unit 04 regional teaching translations

`staging/examples/translate_unit04_regional_data.py` creates English teaching copies of the existing historical exports. Run it with `--source-dir <original-exports> --output-dir <teaching-package>`. It translates headings, introductory text and comma-separated regional descriptors, retaining source values, symbols, IDs, years and indentation. Output includes an original/English crosswalk and provenance manifest. The original exports remain in the external provenance package. On the instructor's request, the two current English TXT inputs, current optional RDS checkpoints, crosswalk and source notes are public downloads in `docs/assets/data/unit04/`. Keep them synchronized with the validated course files; do not add superseded versions or solution scripts.

Active learner inputs are `regional-land-use-1996-2014.txt` and `regional-crop-yields-1999-2015.txt`, both UTF-8. The worked example generates `Output/lu_clean.rds`; the crop assignment specifies `Output/cp_clean.rds`. The translation script does not generate RDS checkpoints. These have been reconciled separately with the revised metadata/types; original checkpoints and numerical comparison evidence are retained in the external provenance package. Unresolved administrative types remain unavailable. Revised Unit-04 Rmds use local `Data/` paths and create outputs separately; their rendered Markdown must retain the course-page metadata and links when integrated.
