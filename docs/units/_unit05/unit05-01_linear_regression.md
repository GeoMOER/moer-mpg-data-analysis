Compute simple statistical linear regression models that relate a dependent to an independent variable.

<!--more-->

## Learning objectives
At the end of this session you should be able to
* discuss different indicators relevant for the assessment of linear regression results,
* use residual plots to discuss the mean pattern, error spread and normal approximation;
* explain which assumptions need information about the sampling design;
* numerically evaluate properties of linear regressions.


Start with the modeling explanation and the [regression example]({{ site.baseurl }}/unit05/unit05-03_linear_regression.html). Then work through [Checking Regression Assumptions]({{ site.baseurl }}/unit05/unit05-03a_assumptions.html) before [Assignment 05]({{ site.baseurl }}/unit05/unit05-04_assignment.html).
