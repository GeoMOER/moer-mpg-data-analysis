## Improve one familiar figure

Use a plot and dataset from an earlier unit. The [R Graph Gallery](https://www.r-graph-gallery.com/){:target="_blank"} can provide ideas; adapting your existing base R plot is enough.

1. State what the reader should learn from the figure.
2. Improve its labels and units, then choose colors that suit the variable. Use line types or symbols as well if several groups must be distinguished.
3. Check the legend and readability at the size you intend to show it. Compare the revised figure with the original.
4. Show the result and briefly explain which change helps the reader most. Mention one remaining limitation.

Keep the code and figure in your course project. This is an in-session exercise; no additional portfolio submission or new plotting package is required.
