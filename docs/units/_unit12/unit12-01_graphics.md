Improve a familiar course figure by choosing meaningful colors, clear labels and readable legends.

<!--more-->

## Learning objectives
At the end of this session you should
* choose qualitative, sequential or diverging colors to match the variable,
* explain how map class boundaries affect the display, and
* revise one familiar figure and explain the improvement.


## More on this topic
Start with the palette and map examples, then use the [gallery activity]({{ site.baseurl }}/unit12/unit12-06_R_graph_gallery.html) to improve a plot using familiar course data. This is an in-session activity, with no additional portfolio submission.
For optional background, see [Creating publication quality graphs in R](https://rstudio-pubs-static.s3.amazonaws.com/9575_8a5dc0315e7d48ea94e0fd2546727041.html){:target="_blank"}, a tutorial developed for a University of Marburg workshop.
