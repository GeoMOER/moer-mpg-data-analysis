Data analysis is an essential skill for professional geographers. Technological advances have made it easier to collect and distribute large datasets, increasing the need for both statistical and computing skills.

Working with data involves organizing, processing, describing, and interpreting datasets. This course uses R to build data-analysis workflows and automate common tasks with a flexible programming language.

# Intended learning outcomes
By the end of this course, you should be able to:
  
* organize datasets and intermediate analysis results in a structured way,
* use Git for version control and GitHub to document workflows, collaborate, and manage issues and tasks,
* build data-analysis workflows in R using scripts and functions from third-party packages,
* model relationships among variables and estimate uncertainty in the results, and
* critically evaluate your analyses.
